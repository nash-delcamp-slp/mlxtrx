# Show differences between original and modified INI files

Show differences between original and modified INI files

## Usage

``` r
show_ini_diff(
  original_lines,
  modified_lines,
  missing_settings,
  incorrect_settings
)
```

## Arguments

- original_lines:

  Original INI lines

- modified_lines:

  Modified INI lines

- missing_settings:

  Missing settings that were added

- incorrect_settings:

  Incorrect settings that were replaced
